CABALLERO! — Newsstand full site
================================

index.html
  The whole site as ONE self-contained file. Double-click to open, or
  drop it on any host (Netlify, Vercel, GitHub Pages, S3, cPanel) as-is.
  Rename it if you like; index.html is just the conventional entry point.

  Still loaded from the internet at runtime:
    - Google Fonts (Archivo Black, Barlow Condensed, Source Serif 4,
      Space Mono, Architects Daughter)
    - Placeholder photography from picsum.photos
  Both are placeholders you will replace anyway. To go fully offline,
  self-host the font files and swap the picsum URLs for your own images.

source/
  The editable original: Newsstand - Full Site.dc.html + support.js.
  Keep these two together in the same folder. Edit this version, not
  index.html (index.html is compiled output).

Swapping in your own images
  In source/Newsstand - Full Site.dc.html, search for "picsum.photos"
  and replace each URL with a path to your own file, e.g. img/hero.jpg.
  Then re-export.

Pages
